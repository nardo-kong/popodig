# Source Notes — Historical Reference Only

Files in this directory preserve early concept material for provenance and idea history.

**They are NOT implementation authority.**

The original concept contains exploratory ideas that were later narrowed, replaced, or deferred. In any conflict, follow the authority order in the project root `AGENTS.md`, especially:
1. Decision Register
2. Product Vision
3. GDD
4. current system/world specifications

Examples of ideas in historical notes that are not automatically approved for V1 include large subway-scale areas, ancient mouse civilization scope, heavy simulation systems, combat, infinite-world interpretation, and any framing that turns free excavation into explicit route-choice UI.
