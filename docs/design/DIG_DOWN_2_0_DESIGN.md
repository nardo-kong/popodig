## 產品目標

玩家帶領自主工作的鼠群，把陌生地下世界逐漸變成有生活痕跡的家。
挖掘要帶來期待、發現和用途，家園發展要自然產生下一個探索理由。

核心循環：觀察承諾 → 選擇前沿 → 挖掘 → 發現／獲得 → 搬運 →
加工／使用 → 改造家園 → 解鎖群體能力 → 深入 → 更大的家。

自由挖掘、有限連續世界、空間決策與鼠群自主仍是產品原則。
知識進度與群體能力共同成長；玩家不逐鼠換裝或分配背包。

## 發現與可見承諾

- 小發現提供食物、可用材料或純收藏快樂；中發現形成資源點／可用空間；
  大發現保留根系、水、舊鼠穴等五段生命週期。
- 前沿的無／微弱／明顯／強烈信號對應真實資料；只在探索邊緣提供局部承諾，
  不繪出整個隱藏物件或穿透全圖迷霧。
- 同一時刻的可選前沿應在價值、距離、硬度或風險上有差異。
- 不能把「每格掉泥」當作發現經濟；可預見的小目標要讓玩家願意繞路。

## 資源、供應鏈與能力

食物、建材、石材、礦石、金屬、收藏品採穩定 ID。舊 FOOD 與
GENERAL_MATERIAL 必須保留兼容或明確遷移。材料可由實際探索持續取得，
不能依靠開局十單位或 QA 注入完成發展。

輕量生產以少量配方將資源轉成建材／升級用途。鼠鼠自主供料、加工、搬運；
玩家設區與工作目標。缺料、滿倉與遠距離要可理解、可透過布局改善。

群體能力可分 Basic、Reinforced、Deep Digging 等少量階段，讓新材料、
加工成果與新的探索機會相連。能力不替代讀取信號、準備風險與選路。

## 規劃的理由

實際搬運與生活往返消耗工作時間。已有路徑成本應重用，避免再按距離重複扣速。
來源、倉庫、生產區與工作前沿形成相依關係；近倉庫、捷徑與臨時生活區有收益。
後方主基地重舒適安全，前線重就近供應；前線是區域布局角色，非逐鼠指派系統。

## 深度、收藏與家園

- 安全開局先給發現回報，再逐步引入水、穩定度和更深的價值／風險。
- 危險能預警、能準備，有繞路、密封、加固、排水或重規劃的多種回應。
- 圖鑑先做 15–20 項；未知條目保留期待，收藏可只有開心回饋與展示。
  不擅自把收藏變成必需的永久能力數值。
- 三章依序教發現與安家、供應與風險、深入與重建家園；保留最終暖巢和通關後沙盒。
- 家園透過人口、區域生活、收藏與歷史痕跡呈現長期成果。

## 資料與存檔契約

新發現實例、獎勵領取、實際世界變更、資源堆、設施輸入／進度／輸出、
群體能力及圖鑑狀態都是 authoritative simulation，不由畫面推算。
保留完整世界與特徵狀態，不能只按 seed 重生已改造的世界。

新增 2.0 狀態採一次 v2→v3 遷移入口；v1→v2→v3 鏈保留。
v3 的新增可選欄位有安全預設；有破壞性變更時再增版本。舊物品 ID、
缺少新欄位、未知 ID、領獎中的讀檔與生產中斷均需有明確行為。
世界生成版本變動與 save schema 分別處理，支援可恢復的舊世界或明確報錯，
不能靜默丟進度或用新世界覆蓋原檔。

## 驗收與非目標

工程驗收：確定性、資源守恆、領獎一次、可恢復作業、可靠存讀與相關性能。
玩法驗收：玩家能比較前沿、預測信號、為發現繞路、因運輸而重布局，
並在處理危險後繼續建設。自動化 smoke 與實際人玩分別記錄。

首局具體時間／密度、配方成本與能力門檻為 provisional，以資料調整；
不能宣稱尚未觀察的玩家體驗已通過。

本輪不增加戰鬥、個體工具欄、深配方樹、複雜生理需求、無限世界或真實流體。
水／穩定度等現有系統重用；原有塌方重設計與 Priority 動詞保留為已知遺留項。
