## 連續實施與測試節奏（用戶 2026-10-21 授權）

提交 Issues 後即開始實作，依依賴持續推進，不逐階段重複請求批准。
每項執行受影響的單元／整合增量、核心不變量與必要短 smoke；
程式變更先做 import／parse。文件變更只檢查連結、來源與規格一致性。

完成一批後才做較大回歸：

1. P0 核心：發現、線索、資源、保存與既有水／穩定核心。
2. 物流／生產／能力：作業互動、中斷恢復、供應鏈 smoke。
3. Worldgen／戰役：完整種子矩陣、重播、相關畫面與章節 smoke。
4. 最終 RC：全套測試、存檔 soak、性能、dev／release 與完整可玩流程。

同一批小改不重跑 288 seeds／全截圖；新失敗或核心風險才追加必要檢查。
報告每次選了哪些測試及原因，不以測試數量當成功指標。
歷史 1299/1299 與 288/288 僅作舊版參考，本輪必須有新的可追溯結果。
