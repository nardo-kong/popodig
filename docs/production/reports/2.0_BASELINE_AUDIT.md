## 2. 1.0 系统清单与 2.0 处置判定

### 2.1 可直接复用（不改）
- `WorldGrid`/`CellData`（`src/domain/world/`）：PackedArray 平铺存储 + RLE 存档 + checksum，新发现数据可走 `feature_ids`/metadata 通道。
- `WaterSystem`（tile 级整数水量、capacity 4、下行优先）、`StabilitySystem`（per-material 跨度、三级预警、半径 ≤3 塌陷）、`SealSystem`。
- `GridPathService`（距离场 + 拓扑修订）、`FogOfWarView`（presentation-only，BFS 半径 4）。
- `ColonySimulation`/`MouseAgent`/`JobSystem` 组合根、`fixed_tick` 顺序、自动搬运。
- `SaveService`（版本化迁移链、原子写）、`SessionTelemetry`、`LocalizationService`、`AudioDirector`、`VFXPool`、通知系统、`ChapterModel` 三章骨架。

### 2.2 需扩展（保留结构，加内容）

### 2.3 需新建（1.0 无对应物）
- **Discovery 数据模型**（ID/类型/稀有度/深度/信号/奖励三层：小/中/大）——20.1。
- **生产体系**（Recipe 数据、生产设施、输入输出、生产作业、完成状态）——1.0 完全没有 crafting/production，`ColonyJob.Type` 需新作业类型——20.5。
- **全局能力升级**（鼠群级，非个人装备；与 D-022「升级不替代学习」需共存表述）——20.6。
- **运输距离模型**（来源→仓库→生产区→前线；搬运时间/有效工时/紧急响应受距离影响）——20.4。
- **收藏图鉴**（15–20 条，未发现 `???`，存档+migration）——20.8。
- **家园成长/成就**——20.11。

### 2.4 判定为"不重构"的争议点
- `DigSystem` 虽无能力档位，但 `_create_job()` 单点注入 `required_work`，扩展即可，不推翻。
- `ItemSystem` item_type 为裸 String，加 ID 低摩擦，不重构。
- 1.0 PM 反馈中「塌陷系统不推翻」的遗留决定继续有效。

## 3. 八个必答问题

1. **可直接复用**：WorldGrid/CellData、水、稳定、密封、寻路、迷雾、鼠群/Job 骨架、Save/Telemetry/本地化/音频、通知、ChapterModel 骨架。
2. **需扩展**：ItemSystem（资源 ID/分类）、SignalSystem（前沿四档呈现）、Worldgen（v7 发现分层+新 validator）、Zone（生产区）、DigSystem（能力档）、ChapterModel/Tutorial（三章重排）、Telemetry（8 项新指标）、HUD 资源显示。
3. **需重构**：无整系统重构。局部结构性新增：`ColonyJob.Type` 增加生产作业、`colony_simulation` tick 顺序中插入生产系统（置于 job system 之前/之后需在 20.5 Plan 决定）。
4. **影响存档的数据结构**（预计 schema v2→v3）：
   - 新资源 ID → `colony.items.piles[].item_type`（String，天然兼容，但需 migration 校验白名单）。
   - 生产设施/队列状态 → `colony` 新节。
   - 全局能力 → `progression` 或新 `abilities` 节。
   - 图鉴 → 新 `codex` 节（发现/收集/完成度）。
   - Discovery 实例 → worldgen metadata 由 seed 重生成（与 1.0 同策略），仅"已发现/已收集"状态入档。
   - 迁移要求：链式 migration、失败不静默丢进度、round-trip soak 复测。
5. **影响 worldgen**：发现密度分层（每 strata band 小/中/大发现布点）、信号发射器扩展（新资源/收藏类通道）、深度-价值-风险梯度、首局节奏（首次发现/资源/风险/升级时机）、新 validator×9、288 seeds 重跑、repair 策略新增。**p95 600ms 预算为最大约束。**
6. **影响性能**：worldgen 新阶段与 9 个新 validator（重点）；新资源种类增加 `ItemPile` 数量与 haul job 量（存储/搬运寻址）；生产系统每 tick 开销（应事件驱动而非轮询）；图鉴/发现 UI 为低频。运行时预算不变：60 FPS 桌面、无多秒卡顿。
7. **可纯呈现层完成**：前沿信号的视觉化（半暗带/粒子提示，不穿透迷雾）——但信号强度数据本身在 simulation；图鉴 UI、资源 UI 分组、升级反馈演出、发现时刻演出。**注意 4.3 原则：呈现不能代替玩法。**
8. **必须进入 authoritative simulation**：发现生成与奖励（20.1）、资源 ID/分类/仓储/采集/搬运（20.3）、运输距离对搬运时间的影响（20.4）、生产输入输出与完成（20.5）、能力档对挖掘的处理门（20.6）、深度风险/价值曲线（20.7）、图鉴发现状态（20.8）。

## 4. 2.0 改动边界（Gate 0 声明）

- 不推翻：水、稳定、密封、寻路、迷雾、鼠群自主模型、存档机制、worldgen 8 阶段管线骨架。
- 新增：Discovery 模型、生产体系、全局能力、运输距离模型、图鉴、成就/家园成长、Worldgen v7 验证器。
- 存档：v2→v3，一次迁移，保持 v1→v2→v3 链。
- **决策登记冲突备案**：
  1. D-017（V1 资源仅 Food+General Material）与 2.0 资源体系（+BuildingMaterial/Stone/Ore/Metal/Collectibles）冲突。2.0 设计文档已获 PM 批准，视为对 D-017 的显式修订；建议在 `00_DECISION_REGISTER.md` 增补修订条目（待 PM 确认后执行，本阶段不改）。
  2. D-022「升级不替代学习」与 20.6 全局能力升级：按 2.0 文档第 7 节执行（鼠群级能力，非个人工具），并在设计中保持知识型进度（信号识别度）并存。
  3. 1.0 遗留：GDD §3.5 优先级动词未实现、塌陷系统 PM 顾虑——2.0 任务书未列入范围，维持遗留状态。
