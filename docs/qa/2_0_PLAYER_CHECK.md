# 2.0 實際試玩記錄卡

對應 #3 Gate A、#4 Gate B、#15。工程 smoke 已通過；以下仍待真實觀察。
保留不熟悉遊戲的試玩者原話，不把引導後答案當作自主理解。

## 每局記錄

版本／commit、seed、平台、語言、開始結束時間、既有經驗、是否接受提示。
開發模式資料只存在本地；自動腳本報告不可填進人玩欄。

## 前 5–10 分鐘

- 首次動手前，請玩家指出想挖的方向及預期回報，記錄原因。
- 是否自行注意小芽／纖維／礦光；取得回報後是否想找下一處。
- 能否分辨兩個前沿在價值、路程、硬度、風險上的差異。
- 哪段等待沒有目的；首次停止操作、迷失或想退出發生在哪裡。

## 中段到暖巢

- 是否理解原料→工坊→群體能力→更深發現；記下卡住的具體條件。
- 是否因實際往返自行加近倉、捷徑、前線睡眠／覓食；記錄前後布局。
- 危險前是否看懂線索；危險後選擇加固、繞路、封堵／排水還是習慣讀檔。
- 人口增加是否帶來有意思的空間調整；收藏是否令人開心而不成負擔。
- 暖巢目標是否清楚，是否願意通關後繼續建家。

## 結論

分別填 Gate A、Gate B、規劃動機、完整流程：通過／需修改／未觀察。
每項附操作、時間點、玩家原話與截圖；列最高優先級的下一輪改動。
在 #15 留下結果，更新 #3／#4；沒有觀察的項目維持開放。
